# StudyMe

**Живая версия:** https://sereshotes.github.io/study-me/

PWA-трекер личных исследований над собой. Запускаешь **исследование** на срок,
описываешь набор **показателей** (настроение, время засыпания, алкоголь, вес
и т.п.) и периодически **отмечаешься**. Данные хранятся локально в браузере
(IndexedDB), работает офлайн, ставится на домашний экран.

## Запуск

```sh
npm install
npm run dev      # http://localhost:5173
```

Сборка и превью прод-версии:

```sh
npm run build
npm run preview
```

## Деплой (GitHub Pages)

Деплой автоматический: пуш в `main` запускает workflow
`.github/workflows/deploy.yml`, который собирает проект и публикует `dist` на
GitHub Pages. Источник Pages — **GitHub Actions**.

Проект отдаётся с под-пути `/study-me/`, поэтому в `vite.config.ts` задан
`base = '/study-me/'`, а роутинг использует `HashRouter` (устойчив к 404 при
перезагрузке глубоких ссылок на Pages). При переезде на кастомный домен или
user-site поменяй `base` на `'/'`.

## Стек

- **React + Vite + TypeScript**
- **Dexie** (обёртка над IndexedDB) — локальное хранилище
- **vite-plugin-pwa** — манифест, service worker, установка на устройство

## Модель данных

- **Study** — исследование: название, описание, даты, статус (активное / архив).
- **Trackable** — показатель исследования. Типы: `scale` (шкала),
  `number` (число + единица), `bool` (да/нет), `time` (время суток),
  `enum` (выбор из списка), `text` (заметка).
- **Entry** — отдельная отметка по показателю с временем `loggedAt`.
  Чек-ин заполняет несколько показателей сразу, но записи хранятся атомарно.

У каждой сущности есть `id` / `createdAt` / `updatedAt`.

## Структура

```
src/
  types.ts              доменные типы
  db/
    db.ts               описание таблиц Dexie
    service.ts          все мутации (единая точка для будущей синхронизации)
  lib/
    date.ts             форматирование дат, прогресс исследования
    trackables.ts       метаданные типов, форматирование значений
  components/
    TrackableInput.tsx  ввод значения показателя (по типу)
    AddTrackableForm.tsx форма добавления показателя
  pages/
    StudiesPage.tsx     список исследований
    NewStudyPage.tsx    создание исследования
    StudyDetailPage.tsx чек-ин / записи / показатели
```

## План на будущее (синхронизация)

Все записи проходят через `src/db/service.ts`. Чтобы добавить хранение в Google
Sheets или БД, туда же добавляется запись в удалённое хранилище (или очередь
синхронизации) — UI трогать не нужно. Поля `updatedAt` позволяют детектить
изменения при синхронизации.
